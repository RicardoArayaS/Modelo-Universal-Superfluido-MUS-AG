# Modelo-Universal-Superfluido-MUS-AG
Arquitectura computacional y algorítmica del MUS-AG. Este repositorio contiene los motores de simulación en Python diseñados para probar la falsabilidad del modelo, resolviendo la divergencia del problema de los N-Cuerpos y la precesión secular relativista mediante mecánica de fluidos incompresibles y gradientes de presión.
